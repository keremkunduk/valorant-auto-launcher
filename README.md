As explained in project description, this project automates the process of launching valorant thanks to the python image search.

you probably need to change 'oyna.png' and 'guncelle.png' with your own screenshot of play button to make it work

How it works:
  1) Runs the provided valorant shortcut to activate riot client with valorant configs
  2) Starts image search until the play button appears
  3) Detects buttons position and auto clicks
  then quits
